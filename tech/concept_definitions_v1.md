# 컨셉 4개 정의서 v1 — 사진 모을 때 보는 기준

> 2026-08-16 작성. **핀터레스트에서 사진을 고를 때 이 문서를 열어놓고 본다.**
> 컨셉 = `고프코어 · 발레코어 · Y2K · 모리룩` (AGENTS.md §5)
> 아이템 이름은 프로토타입 `CLOSET` 목록(21칸)과 같은 말을 쓴다 — 안 그러면 "내 옷" 매칭이 안 붙는다.

---

## 0. 3초 판별 순서 — 헷갈리면 위에서부터

```
① 기능성 소재(나일론·고어텍스·플리스)나 등산 장비가 보이나?
      YES → 고프코어
② 배가 보이거나 허리선이 골반에 걸쳐 있나? (로우라이즈·크롭)
      YES → Y2K
③ 몸에 붙고, 흰색/핑크 계열이고, 리본이나 튤이 있나?
      YES → 발레코어
④ 헐렁하고 여러 겹이고, 베이지·카키·브라운인가?
      YES → 모리룩
⑤ 여기까지 안 걸리면 → 안 담는다
```

**⑤가 중요하다.** 애매한 사진을 담으면 4개 컨셉이 다시 흐려진다 — 그게 `미니멀/러블리/캐주얼/시크`가 망한 방식이다.

## 1. 고프코어 (Gorpcore)

> **한 줄:** 등산 갈 사람처럼 입고 동네 나가기.
> 이름 유래: GORP = 등산 간식(건포도+땅콩). 아웃도어 장비를 일상복으로.

| | 내용 |
|---|---|
| **핵심 아이템** | 나일론 아노락 · 윈드브레이커 · 카고팬츠 · **카고 쇼츠** · 테크 베스트 · 플리스 · 버킷햇 · 백팩 |
| **신발** | 트레일 러닝화 · **하이킹 샌들(테바·차코) + 양말** · 등산화 · 레인부츠 |
| **재질** | **나일론 · 고어텍스 · 립스톱 · 메쉬 · 플리스** (모두 화학섬유) |
| **색** | 카키 · 올리브 · 블랙 · 그레이 + **네온 포인트 하나** |
| **실루엣** | 헐렁 · 주머니 많음 · 스트랩/버클 보임 |
| **여름 성립** | 테크 반팔 + 카고 쇼츠 + 샌들·양말 |
| **비 오는 날** | ◎ **최강** — 젖어도 티 안 나고 금방 마름 |

**🚫 이건 고프코어 아니다:** 면 100% · 레이스 · 새틴 · 몸에 붙는 것 · 구두

## 2. 발레코어 (Balletcore)

> **한 줄:** 발레 연습복 그대로 밖에 나가기.

| | 내용 |
|---|---|
| **핵심 아이템** | **랩 카디건(앞에서 여미는 발레 상의)** · 리본 · 레그워머 · **튤·시폰 스커트** · 바디수트 · 얇은 리브 탱크 · 볼레로 |
| **신발** | **발레 플랫 · 메리제인** · 리본 끈 슈즈 |
| **재질** | 리브 니트 · 저지 · **시폰 · 튤 · 새틴(리본)** · 메쉬 |
| **색** | **화이트 · 핑크 · 베이지 · 블랙** (파스텔, 채도 낮음) |
| **실루엣** | **몸에 붙음** · 어깨·목·발목이 드러남 · 스커트는 짧거나 무릎 |
| **여름 성립** | 리브 탱크 + 튤 스커트 + 발레 플랫 |
| **비 오는 날** | ✗ **최약** — 플랫은 젖고 튤은 늘어진다 |

**🚫 이건 발레코어 아니다:** 카고 · 나일론 · 형광 · 로고 · 청키 스니커즈

| | 내용 |
|---|---|
| **핵심 아이템** | **로우라이즈 진** · 베이비티(쫄티) · **캐미솔 · 튜브탑 · 크롭탑** · 미니스커트 · 저지 트랙수트 · 청청 · 바게트백 · 나비 모티프 |
| **신발** | 청키 스니커즈 · 플랫폼 · 뮬 |
| **재질** | **데님 · 벨루어 · 저지 · 메탈릭·홀로그램** · 립 코튼 |
| **색** | 핑크 · 실버 · 데님블루 · 형광 |
| **실루엣** | **상의는 짧고 타이트, 하의는 골반에 걸침.** 배가 보임 |

| | 내용 |

## 6. 사진 모을 때 지킬 것

1. **컨셉당 최소 15장.** 지금 39장(컨셉당 6~13장)으로는 3~4일이면 후보가 마른다.
2. **비 오는 날 사진을 챙긴다.** 지금 장마에 발레코어 1장 · Y2K 0장이다 — 비 오는 날 그 컨셉을 고르면 못 준다.
3. **여름옷만.** 겉옷이 컨셉의 핵심인 사진(트렌치·자켓 필수)은 반팔만 남기면 형체가 사라진다.
4. **⑤에 걸리면 안 담는다.** 애매한 사진 한 장이 컨셉 하나를 흐린다.

### 컨셉별 필요 장수 (목표)

| 컨셉 | 지금 | 비 오는 날 | 목표 |
|---|---|---|---|
| 고프코어 | 7 | 5 | 15 (비 8) |
| 발레코어 | 8 | **1** | 15 (비 6) |
| Y2K | 11 | **0** | 15 (비 5) |
| 모리룩 | 13 | 7 | 15 (비 7) |

> ※ **15장은 에이전트가 정한 값이다** — 반복 방지 텀(고른 것 7일 · 본 것 2일)을 넘겨도 후보가 3장 밑으로 안 마르는 최소선으로 잡았다. 근거 데이터는 없다.
