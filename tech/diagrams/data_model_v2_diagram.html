흐름 3 — 아침 추천 (코어 루프)

sequenceDiagram
  autonumber
  participant U as 앱
  participant S as 서버 /api/recommend
  participant W as weather_cache
  participant DB as Postgres+pgvector
  U->>S: 앱 열기(오늘 추천)
  S->>W: 오늘 날씨(격자 캐시)
  W-->>S: 체감온도·강수
  Note over S: 질의벡터 결정
참고사진 있으면 그 임베딩,
없으면 taste_vector
  S->>DB: 날씨 하드필터 + 코사인 유사도(단일 SQL)
  DB-->>S: 상위 후보 N
  Note over S: MMR 3장 + 이유 문장(템플릿)
  S->>DB: recommendations + items 기록
  S-->>U: 코디 3장 + 이유
