## 1. 8단계 표 (인터넷 통설)

레퍼런스 이미지에 있는 그 표다. 여러 출처를 대조해 **공통되는 것만** 남겼다.

### 28°C 이상 — 무더위
- **상의** 민소매, 반팔 티, 크롭
- **하의** 반바지, 짧은 치마(미니), 린넨 와이드
- **원피스** 린넨·코튼 여름 원피스
- **소재** 린넨, 시어서커, 인견, 얇은 코튼
- **신발** 샌들, 뮬, 메시 스니커즈

### 27~23°C — 따뜻함
- **상의** 반팔 티, 얇은 셔츠, 블라우스
- **하의** 반바지, 면바지, 데님 와이드, 롱스커트
- **아우터** 얇은 셔츠·가디건 (냉방 대비로 들고만 다님)
- **신발** 스니커즈, 샌들, 로퍼, 플랫

### 22~20°C — 선선함
- **상의** 긴팔 티, 블라우스, 얇은 니트
- **하의** 면바지, 청바지, 슬랙스, 롱스커트
- **아우터** 얇은 가디건 (아침저녁용)
- **신발** 로퍼, 스니커즈

### 19~17°C — 서늘
- **상의** 후드티, 맨투맨, 스웻셔츠, 얇은 니트
- **하의** 긴바지 (청바지·슬랙스)
- **아우터** 얇은 가디건, 얇은 재킷
- ※ *활동하기 가장 좋다*고들 하는 구간

### 16~12°C — 간절기
- **상의** 맨투맨, 셔츠, 니트
- **하의** 청바지, 슬랙스 / 스커트 + **스타킹**
- **아우터** 재킷, 가디건, 청재킷, 야상, 트렌치, 가죽 재킷
- ※ **아침저녁과 낮의 차이가 가장 큰 구간** — 아우터는 벗을 수 있는 걸로

### 11~9°C — 초겨울 문턱
- **상의** 니트, 기모 없는 두꺼운 상의
- **하의** 청바지, **기모바지**
- **아우터** 트렌치코트, 야상, 점퍼, 경량 패딩
- **소품** 스타킹, 가벼운 머플러

### 8~5°C — 겨울
- **상의** 히트텍·폴라티 + 니트 (**레이어드**)
- **하의** 기모 팬츠, 레깅스, 두꺼운 바지
- **아우터** 울 코트, 가죽 옷, 무스탕, 경량 패딩
- **소품** 목도리, 내복

### 4°C 이하 — 한겨울
- **상의** 기모 맨투맨·후드, 히트텍
- **하의** 기모/누빔 바지
- **아우터** 패딩, 두꺼운 코트, 누빔 옷
- **소품** 목도리, 장갑, 부츠

## 2. 한 줄 요약 (외우기용)

| 기온 | 한 줄 |
|---|---|
| 28°C↑ | 민소매·반바지·린넨 |
| 27~23°C | 반팔 + 얇은 셔츠 |
| 22~20°C | 긴팔 + 가디건 챙기기 |
| 19~17°C | 맨투맨·후드 + 긴바지 |
| 16~12°C | 재킷·가디건 **필수** |
| 11~9°C | 코트·점퍼 + 기모 시작 |
| 8~5°C | 울코트·가죽 + 히트텍 |
| 4°C↓ | 패딩 + 목도리·장갑 |

**경계 4개만 기억하면 된다:** 23도(반팔) · 20도(긴팔) · 17도(아우터) · 9도(기모).

## 3. 저장소 CSV와 대조

> ✅ **2026-08-16 갱신 — 8밴드가 CSV에 전부 들어갔다.** 파일명도 `..._v1_summer_women.csv` → **`rainism_outfit_rules_v2_allseason_women.csv`** 로 바뀌었다(이름이 거짓말하지 않게).

우리 정본 CSV는 원래 **여름 4밴드**만 다뤘고, 그 구간이 인터넷 표의 위쪽 4칸과 정확히 같았다. 이번에 아래 4칸을 §1에서 옮겨 넣었다:

| 인터넷 표 | 우리 CSV | 상태 |
|---|---|---|
| 28°C 이상 | 28°C 이상 (무더위·폭염) | 원래 있음 |
| 27~23°C | 23–27°C (따뜻함) | 원래 있음 |
| 22~20°C | 20–22°C (선선함) | 원래 있음 |
| 19~17°C | 17–19°C (서늘) | 원래 있음 · **"엣지" 딱지 떼고 정규 밴드로** |
| 16~12°C | 12–16°C (쌀쌀) | ✅ **추가** |
| 11~9°C | 9–11°C (추움) | ✅ **추가** |
| 8~5°C | 5–8°C (겨울 초입) | ✅ **추가** |
| 4°C 이하 | 4°C 이하 (한겨울·한파) | ✅ **추가** |

**CSV에는 인터넷 표에 없는 게 더 있다** — 그게 이 표를 그대로 못 쓰는 이유(§4)를 메운 부분이다:

- **강수 5단계**(강수없음 / 1mm 미만 / 1–3mm / 3–10mm / 10mm+) → 우산·신발·기장 규칙 `[2]`
- **일교차 4단계**(5 미만 / 5–8 / 8 이상 / 10 이상) + **냉방·난방 상시 규칙** `[3]`
- **비·눈 올 때 피할/유리한 소재** `[4]`
- **강설·결빙 6단계**(진눈깨비 / 적설 1cm 미만 / 1–5cm / 5cm 이상 / 빙판) `[6]` ← 2026-08-16 신설
- **기상청 필드 매핑** `[5]`

⚠️ **주의 두 가지**
1. **제품 니치는 여전히 "여름부터"다**(AGENTS §2). CSV가 전 계절을 담았다고 스코프가 넓어진 게 아니다 — **라이브러리 사진이 여름 것뿐**이라 겨울 밴드를 켜면 후보가 0장이 된다.
2. **적설(SNO)은 아직 안 받아온다.** `api/weather.js`는 TMP·REH·POP·PCP·PTY·TMN·TMX만 읽는다. `[6]`의 적설 단계를 실제로 쓰려면 **SNO를 먼저 받아와야 한다** — CSV `[5]`에 "⚠️ 미구현"으로 적어뒀다.

## 4. ⚠️ 이 표를 그대로 믿으면 안 되는 이유

정리하면서 확인한 것들이다. **넘어가면 나중에 물린다.**

1. **출처가 없다.** 나무위키도 *"구글링하면 이미지가 많지만 다 비슷하다"* 며 **SNS 카드뉴스 단골 소재**라고만 한다. 기관 기준도, 연구 근거도 아니다. 서로 다른 버전끼리 아이템이 조금씩 다르다.

2. **기온 하나만 본다.** 습도·바람·햇빛·비를 전부 무시한다. 습도 80%의 25도와 건조한 25도는 **입을 옷이 다르다.** (우리 CSV가 `습도 70%↑면 +1밴드 보정`을 넣은 이유다.)

3. **비를 아예 안 다룬다.** 이 제품의 핵심이 비인데 **표에는 우산도 신발도 없다.** §1을 하드필터로 쓰면 **비 오는 날 린넨·스웨이드를 추천하게 된다** — 원칙 2("날씨는 틀리면 안 된다") 정면 위반이다. 강수 규칙은 반드시 CSV[2]·[4]를 쓴다.

4. **최저기온이냐 최고기온이냐가 안 적혀 있다.** 아침 9도 낮 19도인 날은 두 칸이 동시에 해당한다. → **일교차 규칙**(CSV[3])이 따로 필요한 이유.

5. **실내를 안 본다.** 한여름에도 냉방 때문에 어깨 덮을 게 필요하다(CSV[3] 냉방 상시 규칙).

6. **개인차가 크다.** 같은 15도에서 누구는 패딩, 누구는 반팔이다.

> **결론:** §1은 **가을·겨울 확장 때 참고할 출발점**이지, 그대로 옮길 규칙이 아니다.
> 실제 규칙으로 승격하려면 ①습도·바람 보정 ②강수 덮어쓰기 ③일교차 처리를 붙여서 **CSV에 같은 형식으로** 추가해야 한다.
