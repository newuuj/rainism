# reference — 참고자료 두는 곳

디자인·UX 참고로 모아둔 것들. **정본이 아니다.** 여기 있는 건 아무것도 규칙이 아니고,
결정은 `submission/`·`AGENTS.md`에만 적는다.

- 앱 스크린샷, 무드보드, 캡쳐, 링크 메모 등 아무거나
- 파일 이름에 **뭐가 참고할 점인지** 적어두면 나중에 찾기 쉽다
  예: `토스_온보딩_질문3개.png`, `애크컬리_날씨카드.png`
