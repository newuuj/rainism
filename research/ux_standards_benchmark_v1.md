# rainism — UX 표준 & 벤치마크 v1

> 이 분야 잘 만든 제품 5개의 실제 화면·흐름·용어에서 뽑은 **UX 표준**과, rainism이 ①그대로 따를 것 ②새로 안내할 것 ③일부러 거부할 것.
>
> *작성: 2026-07-07 · 근거: 에이클로젯·Whering·Cladwell·Stylebook·웨디 실제 UX 조사*

---

## 핵심 발견
**"매일 날씨 기반 3코디"는 Cladwell이 이미 하고 있어 완전 새롭지 않다.** rainism의 진짜 새로움 = **① 내 옷으로 ② 결정 대행 프레이밍 ③ 안전빵 1개 ④ 한국 날씨 깊이 + 순서 뒤집기.**

## 벤치마크 5종
| 앱 | 시그니처 | rainism에 주는 것 |
|---|---|---|
| 에이클로젯(한국 강자) | (+)→사진→AI배경제거·자동태깅, 여러 옷장, 중고거래 | 국내 표준 온보딩·용어 |
| Whering(무료 UX 강자) | "Dress Me" 셔플, Planner(날씨+3옵션), 소셜 무드보드 | 코디빌더·플래너 배치 |
| Cladwell(결정 특화) | **매일 3코디(날씨기반)**, refresh/edit, 캡슐, 로깅→프로필 | "3개" 선례·일일 제안 흐름 |
| Stylebook(15년 최장수) | Looks·Calendar·Packing·Stats, cost-per-wear | 성숙한 용어·통계 관습 |
| 웨디(직접 경쟁) | '오늘의 코디' -15~35℃, 9스타일 필터, 크리에이터(남의 옷) | 피할 반면교사 |

## 1. 공통 표준 (흐름 · 용어 · 배치)

### 🔄 흐름 표준
1. **온보딩 = 옷장 채우기부터** *(단, #1 마찰 원인)*
2. **아이템 추가:** 하단 **(+)** → 사진 → **자동 배경제거** → **AI 자동 태깅**(카테고리·색) → **사용자 검토·수정** → 저장
3. **코디 만들기:** 그리드 조합 / **셔플**(자동) / 2~4피스 콜라주
4. **일일 제안·계획:** 상단 **날씨+날짜 헤더** + 오늘 코디(제안 or 기록) + **refresh**
5. **착장 로깅 → 캘린더 + 통계**(활용률·최다착용·cost per wear)
6. **소셜(있으면):** 친구 옷장·무드보드 보기·팔로우

### 🏷️ 용어 표준 (새로 만들지 말 것)
`옷장/Closet` · `아이템/Item` · `코디/Outfit/Look` · `배경제거` · `카테고리`(상·하·아우터·신발·액세서리) · `캡슐(Capsule)` · `오늘의 코디` · `셔플` · `플래너·캘린더` · `패킹` · `OOTD/착장기록` · `통계/cost per wear` · `영감·무드보드` · `TPO`

### 📐 배치 표준
- 하단 탭 네비 + **하단 중앙 (+) = 아이템 추가**
- 옷 **그리드 뷰**(카테고리별 플랫레이 썸네일)
- 코디빌더 = 타입별 슬라이더/레이어(상·하·신발)
- 상단 **날씨+날짜 헤더**
- **코디 카드** + 액션(refresh·edit·좋아요·저장)
- 통계/스타일 프로필 화면

---

## 2. ✅ 그대로 따라야 할 것 (유저 학습됨 → 어기면 마찰)
1. 하단 탭 + 중앙 (+) 아이템 추가
2. 사진→자동 배경제거→AI 자동 태깅→**검토·수정**(태깅 ~50% 오류 업계 공통 → 수정 UI 필수)
3. 표준 용어 채택(옷장·아이템·코디·OOTD·배경제거)
4. 옷 그리드 + 카테고리 분류
5. 상단 날씨+날짜 헤더 + 코디 카드 refresh·좋아요·저장
6. 착장 로깅 → 통계 루프(습관화+개인화)
7. "3개 제안"은 Cladwell 선례로 낯설지 않음 — 그대로 가되 프레이밍만 바꿈

---

## 3. 🆕 rainism에만 있어 새로 안내할 것 (온보딩·툴팁 필요)
| # | 새로운 것 | 왜 안내 필요 |
|---|---|---|
| 1 | 날씨-트리거 진입점(앱 여는 이유="아침·날씨") | 기존 앱은 옷장이 홈 → 멘탈모델 전환 |
| 2 | 정확히 3개 + 탭 한 번 = 결정 대행 | 무한 그리드·셔플과 반대 → "왜 더 안 보여줘?" 선해명 |
| 3 | 추구미 퀴즈 먼저 → 옷 나중(순서 뒤집기) | 표준은 옷부터 → "옷 없이 코디부터" 이유 안내 |
| 4 | "내 옷 안에서"(≠웨디식 크리에이터) | 남의 코디 구경으로 오해 방지 |
| 5 | 왜 3개인가 / 안전빵 1개 | 1=강요, 3=통제권. 신뢰 절벽 방어 |
| 6 | 궂은 날 대비 경고("크록스 신지 마세요") | 기존 앱에 없는 안전 안내 |
| 7 | 피드 자동 기온·강수 태그 | 경쟁앱에 없는 훅 → 새 개념 |
| 8 | 체감온도 "숫자"만 읽음(온도표 안 봄) | "앱이 대신 읽는다"가 가치 |

---

## 4. ⛔ 표준이지만 일부러 안 따를 것 (논지와 충돌)
- 무한 셔플/무한 그리드(Whering·에이클로젯) → 선택 과부하 재발
- 90+ 기능(Stylebook) → 고수용, 과부하
- 무한 영감 브라우징 → 남의 옷 벽으로 회귀
- 크리에이터 코디가 홈(웨디) → "내 옷" 정체성 희석

> **원칙: 입력·용어·배치는 최대한 표준을 따르고, "결정 방식"에서만 과감히 이탈한다.** 낯섦을 한 곳(결정 대행)에만 몰아야 학습비용이 관리된다.
