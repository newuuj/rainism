# §0. 성공 = 관찰 가능한 한 행동 ⭐

> ## "아침 외출 준비 중에 앱을 열어, **60초 안에 3코디 중 하나를 '오늘 이거 입기'로 탭**한다."

구성 요소가 전부 관찰 가능:
- **아침 시간대에** (기상~외출 전, 로그 타임스탬프)
- **자발적으로 열어** (푸시 없이도)
- **60초 안에** (탭까지 걸린 시간)
- **3개 중 1개를 탭 확정** (확정 이벤트)

### 왜 이 행동인가 — 리서치 전체가 여기로 수렴
| 리서치 | 근거 |
|---|---|
| JTBD | 메인 잡 = "결정을 대신" → 결정이 일어났다는 유일한 물리적 증거 = 확정 탭 |
| 감정지도 | ④좌절→⑤자괴(최저점) 사이를 끊는 행동. 탭이 일어나면 "대충 회귀"가 없음 |
| 실패요인 | 생존지표 "D1 아침 트리거 리텐션" = 이 행동이 **다음날 또** 일어나는 것 |
| 워크플로우 | 6개 도구 수작업 파이프라인이 이 한 탭으로 대체됐다는 증거 |

### 성공이 아닌 것 (허영·역지표)
- 다운로드·가입·옷 등록 수 → 준비일 뿐
- **체류시간 → 역지표.** 결정 앱은 짧을수록 성공. 홈에서 오래 머묾 = 결정을 못 하는 중
- 셔플·새로고침 연타 = 결정 실패 신호

## 화면 위계 — 키울 것 vs 물릴 것

**원칙 한 줄: "홈은 옷장이 아니라 결정이다."**

### ⬆️ 키울 것 (확정 탭에 복무하는 것만)
1. **3코디 카드 = 홈 그 자체** — 앱 열면 0탭·0스크롤 즉시. 스플래시·옷장 경유 금지
2. **"오늘 이거 입기" 확정 버튼** — 카드마다 하나, 엄지 닿는 하단, 가장 큰 터치 타깃
3. **날씨 한 줄 번역** — *"체감 31° · 오후 소나기 — 발 젖는 신발은 뺐어요"* (결정 근거+안심)
4. **"왜 이 코디" 한 줄 이유** — 랜덤 아님 증명(신뢰 절벽 방어)
5. **안전빵 카드가 1번 자리** — 첫눈에 "최소 이건 입어도 됨"

### ⬇️ 물릴 것
| 요소 | 어디로 |
|---|---|
| 옷장 그리드·태깅·통계 | 두 번째 탭 (홈에서 안 보임) |
| 피드/소셜 | 세 번째 탭 |
| 셔플·편집·"더 보기" | 카드 상세의 2차 액션 — **기본은 3개로 닫음** |
| 시간별 날씨 그래프 | 날씨 탭 or 접기 (홈엔 한 줄만) |
| 쇼핑/어필리에이트 | 빈 슬롯 감지 시에만 |
| "옷 더 등록하세요" 잔소리 | 확정 탭 **이후** 부드럽게 |

> 판별 기준: 모든 요소에 "60초 내 확정 탭을 빠르게 하나, 늦추나?"를 묻는다. 늦추면 뒤로.

| | |
|---|---|
| 이름/나이 | 이서연 · 만 22세 |
| 상황 | 서울 소재 대학 3학년 + 주 2회 카페 알바, 가끔 모임·소개팅 |
| 옷장 | 60~80벌(충분). 충동·기분 구매가 섞여 "연결이 안 되는" 옷장 |

### 4대 핵심 차원
| 차원 | 상태 | 설계 함의 |
|---|---|---|
| **숙련도** | 중하. 안목은 있는데 실행 숙련 낮음 — 남의 코디는 알아봐도 내 옷으로 재현 못 함 | "고수의 결과물"을 완제품으로. 기능 늘리면 과부하 |
| **사용 빈도** | 매일 아침 1회(핵심 트리거). "입을 게 없다" 체감 주 3~4회 | 성패 = D1 아침 트리거 리텐션. 위젯+아침 알림 |
| **시간 압박** | 극심. 옷 결정에 쓸 수 있는 시간 3~5분. 지각 경험 다수 | 탭 한 번 결정. 3분 넘기면 진 것 |
| **사용 환경** | 실행은 100% 혼자(자기 방·아이폰 한 손), 결과물은 종일 "보고당함"(학교·알바·SNS) | 한 손·짧은 응시. 나만보기 기본. "남에게 어떻게 보일까"를 앱이 안심 |

### 하루의 그 순간 (아침 8:10)
알람 두 번 미루고 일어남 → 8:10, 9시 수업 → 옷장 → "어제 입었잖아" → 치마엔 맞는 신발 없음 → 비 온댔는데 원피스? → 3벌 입었다 벗었다 → **무채색 티+청바지 회귀** → 종일 거울 볼 때마다 거슬림.

### 설계 명령 5
① 탭 한 번 결정(3분 내) ② 안전빵 1개 보장 ③ 위젯+아침 타이밍 ④ 나만보기 기본·공적 안심 ⑤ 12벌 전에 첫 코디

### Anti-persona
고르는 과정을 즐기는 사람, 공식 확고한 미니멀리스트, 스타일링 고수 — "결정 대행"이 재미를 뺏는 사람들.

# §2. JTBD — 서연이 rainism에서 끝내려는 일

### 메인 잡
> **"내일 아침 뭘 입을지 마주할 때 — 나를 대신해 오늘의 나·날씨·일정에 맞는 옷을 가진 것 안에서 정해줘서 — 결정에 에너지를 쓰지 않고도 '괜찮게 입었다'는 확신으로 하루를 시작하게 해줘."**

기능적으로는 "착장 정하기"지만, 실제 고용 이유는 **자존감 지키기(감정) + 적절해 보이기(사회)**.

### 세 층위
| 층위 | 끝내려는 일 | 동력 |
|---|---|---|
| ⚙️ 기능 | 오늘 맞는 조합을 최소 결정으로 확정 / 가진 옷 연결 / 어제와 안 겹침 / 궂은 날 낭패 회피 | 막막함·시간압박 해소 |
| ❤️ 감정 | 결정 피로 탈출·아침 에너지 절약 / "괜찮게 입었다" 확신 / 자괴감 회피 / 내가 최종 선택한다는 통제감 | 자존감·안심·통제감 |
| 👀 사회 | "적절하게·센스 있게 입은 사람"으로 보이기 / TPO 맞추기 / OOTD로 표현·인정 / "대충 입은 사람" 회피 | 소속·인정·표현 |

### 잡 스토리 6 (When → I want → So I can)
1. **⏰ 시간 압박** — 5분뿐일 때, 고민 없이 바로 입을 한 벌 → 지각도 찝찝함도 없이
2. **🌧️ 궂은 날** — 비/눈 예보 아침, 신발 신기 전에 "오늘 신으면 안 되는 것" → 낭패 회피
3. **💘 중요한 자리** — 소개팅/발표 날, 자리에 맞으면서 나다운 착장 확신 → 종일 위축 안 되게
4. **📌 영감 격차** — 핀터레스트 코디를 내 옷으로 못 옮길 때, 내 옷으로 비슷한 무드 → "따라 샀는데 어색" 회피
5. **🔁 중복 회피** — 어제 옷 피하다 선택지 줄 때, 안 겹치는 괜찮은 조합 → 매번 새로 고민 안 하게
6. **🌙 저녁 기록** — 오늘 착장이 마음에 들 때, 간편 기록+반응 → 다음에 또 입고 나를 표현

### 지금 고용 중인 대안 (해고 대상)
| 현재 해결책 | 한계 | rainism |
|---|---|---|
| 친구·커뮤니티 "골라줘" | 즉답 없음, 눈치 | 탭 한 번 즉시 3코디 |
| 무채색·유니폼화 | 표현 포기 | 좁히되 3개 통제권 |
| 어제 옷 반복 | 결핍·지루 | 중복 회피+신선함 |
| 대충 입고 후회 | 자존감 유출 | 안전빵 1개 확신 |
| 마네킹·세트째 구매 | 돈, 못 가진 옷 | 이미 가진 옷으로 |

### "일이 끝났다"의 신호
아침 3~5분 내 결정 종료 · 종일 거울 안 거슬림 · "잘 입었다" 자기만족 · 궂은 날 낭패 0 → 제품 지표 = **D1 아침 트리거 리텐션** (§0의 성공 행동과 동일).

### Anti-job
새 옷 사기(쇼핑은 갭필러) / 스타일링 공부·탐색(고수용) / 무한 영감 브라우징(과부하 재발).

# §3. 현재 워크플로우 — 지금 이 일을 실제로 어떻게 처리하나

### 현재 도구 스택 = 손으로 이어붙인 5~6개
| 도구 | 용도 | 한계 |
|---|---|---|
| 날씨 앱 | 기온 확인 | 숫자만 줌 → "그래서 뭘 입어?"는 스스로 |
| 폰 앨범의 "기온별 옷차림표" 캡처 | 20도=긴팔+가디건 대조 | 남이 만든 일반표, **내 옷 아님** |
| 핀터레스트·인스타 저장 | 무드·롤모델 따라입기("손민수") | 따라 사도 어색(내 몸·내 옷 아님) |
| 카톡 친구·커뮤니티 | "골라줘"(소개팅·데이트) | 즉답 없음, 눈치, 매번 못 물음 |
| 거울 + 실물 시착 | 입었다 벗었다 | **최대 시간 싱크** + 방 난장판 |
| 옷장 앱 | 디지털 옷장 시도 | 등록 마찰 방치 / "코디를 안 만들어줌" |

> 지금 "코디 결정"은 날씨앱→앨범 기온표→핀터레스트→카톡→거울을 사람이 잇는 수작업 파이프라인. **rainism = 이 6개를 한 화면으로 압축.**

### 두 가지 모드
**Mode A — 평일 아침(대다수):** 일어남 → 옷장 앞 → 어제 옷 회피 → 조합 안 맞음 → 입었다 벗었다 2~3회 → ⏱ 시간 임계 → 😩 무채색 회귀 → 종일 찝찝. *(이탈점①: 시간 압박에 결정 포기)*
**Mode B — 중요한 날(고관여):** 전날 밤 → 날씨 확인 → 핀터레스트 무드 → 내 옷과 대조 → 맞는 게 없음 → 카톡 "골라줘" → 대기 → 미리 꺼내둠 or 아침으로 미룸. *(이탈점②: 영감을 내 옷으로 못 옮겨 포기)*

### 시간 싱크 (큰 순서)
🥇 거울 앞 입었다 벗었다("20분 허비") 🥈 핀터레스트·인스타 무한 스크롤 🥉 친구 답장 대기 ④ 기온표 대조·일교차 계산

### 이탈점 지도 (Drop-off)
| 이탈점 | 언제 | 결과 |
|---|---|---|
| A. 시간 압박 회귀 | 아침 3~5분 초과 | "대충" → 종일 찝찝 |
| B. 영감 적용 실패 | 따라했는데 어색 | 도전 포기, 안전한 옷 회귀 |
| C. 앱 온보딩 방치 | 12벌쯤 등록하다 | 앱 안 엶(최대 앱 이탈) |
| D. 앱 사용 이탈 | "코디 안 만들어줌/태그 쓸모없음" | 삭제 |
| E. 물어보기 무산 | 친구 즉답 없음 | 스스로 대충 |

### 시사점
① 경쟁자 = 앱이 아니라 수작업 파이프라인 6종 ② 최대 시간 싱크 제거 = "입어보지 않고, 내 옷 안에서, 조합된 채로" ③ 사람들은 이미 규칙표를 수동으로 함 → *"기온표 캡처해 대조하던 거, 앱이 내 옷으로 대신해요"* ④ 이탈점 A(→탭 한 번 3코디)·C(→12벌 전 첫 코디) 정조준 ⑤ Mode B의 "골라줘" 정서 = "항상 대기 중인, 내 옷을 아는 친구".

# §4. UX 표준 & 벤치마크 (요약)

> 상세: [ux_standards_benchmark_v1.md](./ux_standards_benchmark_v1.md)

**핵심 발견:** "매일 날씨 기반 3코디"는 Cladwell 선례가 있어 낯설지 않음. rainism의 새로움 = ①내 옷으로 ②결정 대행 프레이밍 ③안전빵 ④한국 날씨 깊이+순서 뒤집기.

**벤치마크 5:** 에이클로젯(국내 표준 온보딩·용어) · Whering(코디빌더·플래너 배치) · Cladwell(3코디 선례) · Stylebook(용어·통계 관습) · 웨디(반면교사 — 크리에이터=남의 옷).

**✅ 따를 것:** 하단 탭+중앙(+) / 사진→배경제거→AI태깅→**검토·수정**(태깅 50% 오류 업계 공통 → 수정 UI 필수) / 표준 용어(옷장·아이템·코디·OOTD) / 그리드+카테고리 / 날씨+날짜 헤더·코디 카드 액션 / 로깅→통계 루프.

**🆕 새로 안내할 것:** 날씨-트리거 진입점 / 정확히 3개+탭 한 번(왜 더 안 보여줘? 선해명) / 추구미 퀴즈 먼저(순서 뒤집기) / "내 옷 안에서"(≠크리에이터 코디) / 안전빵 1개 / 궂은 날 경고 / 피드 자동 날씨 태그 / 체감온도 숫자만 읽음.

**⛔ 일부러 안 따를 것:** 무한 셔플·무한 그리드 / 90+ 기능 / 무한 영감 브라우징 / 크리에이터 피드가 홈.
