# 프로토타입 회귀 테스트 체크리스트

> **회귀 테스트** = "고치기 전에 되던 게 지금도 되나" 확인하는 것.
> 이 목록은 `rainism_prototype_v1.html` **코드에 실제로 있는 동작**만 뽑은 것이다 (2026-07-14 기준, 커밋 `dfe1b18` + 미커밋 수정분).

## 시작하기 전에 — 이렇게 열어야 한다

```bash
cd ~/Desktop/rainism/프로토타입
python3 -m http.server 8899
```
→ 브라우저에서 **http://localhost:8899/rainism_prototype_v1.html**

> ⚠️ **더블클릭(`file://`)으로 열면 안 된다.** 참고사진 AI 매칭(CLIP)이 `http://` 에서만 켜진다.
> 더블클릭으로 열면 사진을 올려도 "오프라인 데모 모드"로 빠지므로 **B-6, E-4 항목을 테스트할 수 없다.**

> 💡 **매번 처음부터 걷고 싶으면:** 브라우저 시크릿 창을 쓰거나, 오늘 화면 우상단 **↻ 처음부터** 를 누른다.
> (저장된 상태가 localStorage에 남아서, 두 번째부터는 온보딩을 건너뛰고 바로 '오늘'로 간다 — 이것도 테스트 항목이다. C-7)

## A. 온보딩 — 처음 들어온 사람 (9단계)

| # | 누르는 것 | 이렇게 나와야 정상 |
|---|---|---|
| A-1 | 앱 열기 | 스플래시. **도트 수달**이 옷 한 벌 안고 떠 있고, **빗줄기가 떨어진다** |
| A-2 | `시작하기` | 성별 질문 |
| A-3 | `여성 옷을 찾아요` | 나이 질문으로 |
| A-4 | (뒤로 → 다시) `남성 옷을 찾아요` | **"아직 준비 못 했어요" 화면.** 막다른 길이 아니라 탈출구 2개 (`← 돌아가기` / `그래도 구경할래요 →`) |
| A-5 | `20대` (또는 30대) | **개인정보 동의 화면** |
| A-6 | (뒤로 → 다시) `10대` 또는 `40대 이상` | 역시 **탈출구 2개짜리 안내 화면** |
| A-7 | `동의하고 시작하기` | **취향 퀴즈 1번(무드)** — 사진 4장(미니멀/러블리/캐주얼/시크) |
| A-8 | 무드 → 색 → TPO 3문항 | 한 문항 = 한 화면. **질문은 3개가 끝.** 4번째가 나오면 버그 |
| A-9 | 참고사진 화면에서 `사진 없이 취향으로 볼래요` | 날씨 고르는 화면 |

**모든 질문 화면 좌상단에 `← 뒤로` 가 있고, 눌렀을 때 직전 화면으로 돌아가야 한다.**

## B. 코어 루프 — '오늘' 탭 (제품의 심장)

| # | 누르는 것 | 이렇게 나와야 정상 |
|---|---|---|
| B-1 | 날씨 4종 중 하나 고르기 (`장마` / `무더위` / `선선한 비` / `맑고 따뜻`) | **코디 3장.** 첫 진입만 회색 로딩 박스가 잠깐 보였다가 채워진다 |
| B-2 | 날씨 화면 위쪽 **동네 칩** 을 다른 걸로 바꾸기 | 결과 화면 제목이 `오늘 · 관악구` → 고른 동네로 바뀐다. **날씨 탭 머리도 같이 바뀐다** |
| B-3 | 카드의 `🤍 오늘 이거 입을래` | **그 카드가 "옷장에서 꺼낼 것" 목록으로 변신** + 나머지 2장이 흐려진다 + 토스트 |
| B-4 | 방금 고른 그 카드를 **한 번 더** | **결정 취소.** ("두 벌 저장"이 되면 버그 — 하루 한 벌이 원칙) |
| B-5 | 고른 상태에서 **다른 카드** 를 누르기 | **갈아탄다**(교체). 두 장이 동시에 선택돼 있으면 버그 |
| B-6 | `🔄 다른 거 보여줘` | 다른 3장. **버튼이 회색으로 죽고 "오늘은 여기까지예요"로 바뀐다** |
| B-7 | 죽은 리롤 버튼을 또 누르기 | 토스트만 뜨고 아무 일도 안 일어난다 (리롤은 **하루 1회**) |
| B-8 | `📷 이 사진처럼 골라줘` (사진 파일 선택) | 20~40초 뒤 **3장이 다시 골라지고**, 위에 `📷 올린 사진과 분위기가 비슷한 코디를 골랐어요 · AI 매칭 ON` |
| B-9 | 참고사진 칩의 `✕` | 사진이 빠지고 **3장이 취향 기준으로 다시 골라진다** (사진 넣기 전과 같은 3장) |
| B-10 | `날씨 바꿔서 다시 보기` | 날씨 선택 화면으로. 다른 날씨 고르면 3장이 바뀐다 |
| B-11 | `⏰ 아침에 깨워드릴까요?` — 시각 넣고 `알림 받을래요` | 브라우저 권한 팝업 → **"내일 아침, 여기서 봐요"(잠금화면 위젯 미리보기)** 화면 |
| B-12 | 그 화면에서 `🔔 알림 미리보기` | 실제 브라우저 알림이 뜬다 (권한 허용했을 때) |
| B-13 | 우상단 `↻ 처음부터` | 확인 시트 → `네, 처음부터` 누르면 스플래시로. 기록도 다 지워진다 |

### 👀 B-1에서 같이 봐주세요 — `무난해요` 딱지
39장 중 '무난해요'는 **비 적합 15장 중 5장 / 맑음용 24장 중 8장**뿐인데, 캡쳐해 보니 **3장 다 `무난해요`가 붙어 나온 경우**가 있었습니다.
안전빵은 원래 **3장 중 1장**이어야 신호가 됩니다. 3장 다 붙으면 딱지가 의미를 잃어요.
→ 날씨 4종을 돌면서 **`무난해요`가 몇 장에 붙는지** 세어봐 주세요. 매번 3장 다 붙으면 손볼 곳입니다.

### 🚨 B-8은 이 제품에서 제일 잘 깨지는 곳
사진을 넣었는데 **3장이 안 바뀌면** 화면이 거짓말을 하고 있는 것이다.
사진 넣기 전 3장을 적어두고, 넣은 뒤와 비교하세요. (전에 실제로 이 버그가 있었음 — `AGENTS.md §9-1`)

## C. 기록 탭 — 달력

| # | 누르는 것 | 이렇게 나와야 정상 |
|---|---|---|
| C-1 | `📅 기록` 탭 | 달력. **고른 날 칸에 코디 사진 + 날씨 이모지** |
| C-2 | 코디가 있는 날짜 칸 | **팝업**(모달) — 사진 · 이름 · 아이템 · 그날 날씨 · 이유 |
| C-3 | 팝업 안의 `이거 입었어요?` | `✓ 입었어요` 로 바뀌고, 달력 칸에 **✓** 가 붙는다 |
| C-4 | 코디 없는 날짜 칸 | 토스트 "이 날은 담은 코디가 없어요" (팝업 안 뜸) |
| C-5 | `‹` `›` 이전/다음 달 | 지난 달로 이동. **다음 달(미래) 버튼은 비활성** |
| C-6 | 기록 하나도 없는 달로 이동 | 빈 화면 대신 **"아직 기록이 없어요" + 설명** |
| C-7 | 위쪽 `👕 아직 안 알려준 날이 N일 있어요` 배너 | 그 날 팝업이 열린다 |
| C-8 | **오늘 탭 맨 위 "어제 이거 입었어요?" 카드** | `입었어요` / `아니요` / `✕` 3개 다 눌러본다. 답하면 카드가 사라진다 |

## E. 예외 경로 — 우하단 `🧪 상황` 버튼

**이게 없으면 손으로는 절대 못 가보는 화면들.** 상황을 바꾼 뒤 **처음부터 다시 걸어야** 한다.

| # | 상황 | 이렇게 나와야 정상 |
|---|---|---|
| E-1 | **앱을 언제 열었나 → 밤** | 결과 화면에 **🌙 "지금은 밤이에요 — 내일 아침 코디를 골라뒀어요"** 배너. 제목도 "내일 아침". **고른 코디가 달력의 '내일' 칸에 담긴다** |
| E-2 | **위치 권한 → 거부** | 동의 직후 **동네 직접 고르는 화면**. 막다른 길이면 버그 |
| E-3 | **기상청 API → 장애(캐시 있음)** | 결과에 `🕒 날씨를 못 받아와서 어제 오후 3시 기준으로 골랐어요` 회색 띠 |
| E-4 | **기상청 API → 장애(캐시 없음)** | 날씨 화면 제목이 **"지금 밖이 어때요?"** 로 바뀌고 유저에게 직접 묻는다 |
| E-5 | **참고사진 처리 → AI 실패** | 사진은 받되 `⚠️ 못 읽었어요 — 취향으로 골라드릴게요`. **추천은 그대로 나온다** |
| E-6 | **참고사진 처리 → 부적절 차단** | 사진 거부 + **탈출구 2개**(`다른 사진 올리기` / `그냥 취향으로 볼래요`) |
| E-7 | **로그인 → 세션 만료** | 3장은 **그대로 보인다.** `이거 입을래` 누를 때만 로그인 시트가 뜬다. `로그인하고 저장하기` 누르면 **아까 누른 그 코디가 저장된다** |
| E-8 | **라이브러리 → 얇음(2장)** | **2장만** + 제목도 "2가지" + `☂ 실제로 입을 만한 게 2장이라…` 안내. **제목이 "3가지"인데 2장이면 버그** |

## G. 🚨 이 4개는 깨지면 제품이 죽는다 — 반드시 확인

| # | 확인 방법 | 왜 |
|---|---|---|
| **G-1 날씨 하드필터** | **비 오는 날씨 2종**(`장마` · `선선한 비`)을 각각 고르고 **3장 + 리롤 3장 = 6장 전부** 확인. **비에 못 입을 옷(민소매·린넨 등)이 한 장이라도 섞이면 즉시 중단** | `AGENTS.md §4 원칙 2` — 날씨는 틀리면 안 된다. **이게 이 제품이 죽는 방식** |
| **G-2 하루 한 벌** | 한 코디 고르고 → 다른 코디 고르기 → 기록 탭. **달력 그 날 칸에 코디가 하나만** 있어야 한다 | 두 벌이 담기면 "찜한 것"과 "입은 것"이 갈라진다 |
| **G-3 반복 방지** | 코디 고르고 → `↻ 처음부터` 말고 **브라우저 새로고침** → 같은 날씨 다시 보기. **방금 본 3장이 또 나오면 버그** | 북극성이 D1인데, 다음날 어제 화면을 보여주면 안 온다 |
| **G-4 재방문 스킵** | 온보딩 끝낸 뒤 **새로고침(F5)** | 온보딩을 건너뛰고 **바로 '오늘' 3장**이 떠야 한다. 퀴즈를 또 물으면 버그 |

## 🤔 코드 읽다 발견한 것 — 의도인지 확인 필요
