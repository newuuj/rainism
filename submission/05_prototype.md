## 1. 이게 뭔가

**목업이 아니라 실제로 작동하는 프로토타입이다.**

- 추천 엔진(**하드필터 → 무드 유사도 → MMR 다양성 → 안전빵 → 이유 템플릿**)이 HTML 안의 JavaScript로 **실제 구현돼 있다.**
- 코디 사진 **110장은 실사진**이며(Supabase `library_looks`), 무드·색·온도밴드·비 적합성으로 태깅돼 있다.
  - 🔴 **110장 전부 `source_license`가 `unverified`다**(옛 39장 포함). 그중 71장은 출처가 핀터레스트로 기록돼 있다 — 검증용 데모까지만 쓴다. 실서비스는 RG-4에 걸려 못 쓴다(`AGENTS.md §10`).
  - ※ 처음 39장은 사람이 직접, 나중 71장의 `rain_ok`·`is_safe`·`items`·`name`은 **에이전트가 사진을 보고** 매겼다(2026-08-17).
- 날씨를 바꾸면 **추천 결과가 실제로 달라진다.** 화면 전환만 하는 클릭더미가 아니다.

## 4. 자리표시 — 실서비스에서 교체될 부분 (정직하게)

> 아래는 **프로토타입의 한계이자, 실서비스에서 교체가 이미 설계된 지점**이다.
> 🚫 **이 목록에 없는 새 껍데기를 만들지 않는다** (AGENTS.md §9-1).

| 지금 (프로토타입) | 실서비스 | 왜 지금은 이렇게 |
|---|---|---|
| **날씨 = 진짜 기상청 단기예보** ✅ *(2026-08-16 · 웹 주소로 열었을 때)* | 같은 방식 + 서버 캐시 | 고른 동네의 격자번호로 실제 예보를 받는다. 인증키를 감추려고 [`api/weather.js`](../api/weather.js) 를 거친다 — 이 저장소는 공개라 HTML에 넣으면 새어나간다. `file://`(더블클릭)로 열면 그 중계가 없어 **예시 날씨로 내려가고, 날씨 카드 안에 `예시 날씨 · 기상청 못 받아옴` 이라고 밝힌다** *(2026-08-17: 노란 배너에서 작은 칩으로 옮겼다 — 말은 그대로)* |
| **'다른 날씨로 보기' = 데모 4시나리오** | 없음 | 심사자가 비·무더위 같은 다른 날의 결과를 그 자리에서 비교해 보라고 남겨둔 버튼. 누르면 날씨 카드 안에 *'직접 고른 예시 날씨'* 칩이 뜬다 |
| **체감온도 = 아직 기온 그대로** | 체감온도 산출식 확정 후 반영 | 산출식이 문서에 없다(PRD §8.3 미결 · "임의 식 확정 금지"). 계산 안 한 값을 '체감'이라 부르지 않으려고 화면도 **'기온'** 이라고 쓴다. 습도 70%↑ 밴드 보정만 적용(CSV[5]) |
| **동네 = 5개 중 직접 선택** *(2026-07-14)* | **GPS가 자동으로** 잡음 (거부 시에만 수동 선택 = J1) | 날씨와 같은 이유. 화면에도 *"진짜 앱은 GPS로 동네를, 기상청에서 날씨를 자동으로 읽어와요"* 라고 밝힌다 |
| **유사도 = 태그 점수(컨셉 일치도)** 🔴 *(2026-08-17: CLIP 실연동 제거)* | **이미지 임베딩 + pgvector 코사인 유사도** | 참고사진 기능을 빼면서 CLIP도 같이 빠졌다. **확정된 AI 방식이 작동한다는 화면 증거가 지금은 없다** → 스파이크①의 무게가 커졌다 |
| **저장 = 브라우저 메모리**(localStorage) | **Supabase DB (본인만 접근)** | 서버 없이 단일 파일로 돌리기 위해 |
| **알림 = 페이지가 열려 있는 동안만** *(PWA는 붙어 있음 · 2026-08-17)* | **서버 웹푸시**(앱이 꺼져 있어도 옴) | `manifest.webmanifest` + 아이콘을 붙여서 **'홈 화면에 추가'하면 앱처럼 열린다**(FR-21의 전제조건). 다만 알림은 아직 **브라우저 로컬 알림**이라 페이지를 닫으면 안 온다 — 진짜 푸시는 서비스워커 + 서버가 필요하다. 화면도 "위 1단계를 해야 실제로 도착해요"까지만 말한다 |
| **화면의 데모 고지 문구 없음** *(2026-08-17 제거)* | 해당 없음(실서비스는 실사진·실계정) | 첫 화면에 있던 *"포트폴리오 데모 · 실제 날씨/계정 없이 흐름만 보여줘요"* 와 **사진 라이선스 고지 2줄을 화면에서 뺐다**(화면이 지저분해져서). **고지 내용 자체는 이 문서에 남는다** — 코디 사진은 **데모용 참고 이미지**이며, 실서비스에서는 **라이선스 이미지(크라우드픽 확장 라이선스 · 크리에이터 계약)로 교체**된다 |
| **지표 = 📊 패널 (브라우저에 쌓임)** *(2026-07-14)* | **GA4 / Amplitude / Supabase** 로 전송 · **유저 단위** 집계 | `track()` 함수 **속만** 갈아끼우면 된다 — 부르는 8곳은 그대로. 패널에도 *"이 브라우저에서 일어난 일만 셉니다"* 라고 밝힌다 |

### 📊 지표 패널 — PRD §4 "측정할 수 있어야 한다"의 실물 (2026-07-14 추가)

우하단 **📊 지표** 버튼. 계측 이벤트 **6종**(`앱_열기` `퀴즈_완료` `3장_표시` `결정` `결정_변경/취소` `착용_답변`)을 심고, 이걸로 아래를 실제로 계산해 보여준다.

- **D1 아침 재방문** (마지막 방문일과 오늘을 비교) — ⚠️ **더 이상 북극성이 아니다.** 2026-08-16에 북극성이 **알림 도달일 결정률**로 바뀌었는데(PRD §4), **프로토타입은 아직 옛 지표를 잰다.** 알림 도달·오알림은 계측하지 않는다.
- **퍼널** — 앱 열기 → 퀴즈 완료 → 3장 표시 → 결정
- **품질** — 결정률 · **"입었어요" 회수율** *(리롤률은 2026-08-17 「다른 거 보여줘」 폐기로 사라졌다 — 첫 3장의 실패를 재던 눈금이라 대체 지표가 필요하다)*

> ⚠️ **결정률이 거짓말하지 않게 한 두 가지:** ①화면은 저장·착용답변 때마다 다시 그려지므로 **같은 3장은 한 번만** 노출로 센다(안 그러면 분모가 부풀어 결정률이 낮게 나온다). ②**"갈아타기"는 새 결정으로 세지 않는다**(안 그러면 결정률이 100%를 넘는다).

**중요:** 자리표시는 **엔진의 구조가 아니라 데이터 소스**다. 하드필터 → 유사도 → MMR → 안전빵 → 이유의 **순서와 로직 자체는 실서비스와 동일하다.**

### 🚫 참고사진 매칭(CLIP 실연동)은 제거됐다 (2026-08-17)

**이 프로토타입에는 더 이상 CLIP 임베딩이 들어 있지 않다.** 참고사진 기능을 폐기하면서 같이 뺐다 — 사진을 올릴 입구가 없어지면 임베딩을 돌릴 대상도 없다.

> **2026-08-16까지는 진짜였다.** `Xenova/clip-vit-base-patch32` 가 브라우저 안에서 돌아(서버·API키·비용 0원), 올린 사진을 512차원 좌표로 바꾼 뒤 라이브러리 39장과 코사인 유사도로 랭킹했다. 러블리 사진을 올리면 추천 3장이 실제로 러블리 쪽으로 바뀌는 것까지 확인했었다. 코드는 git 이력에 있다.

**🔴 이게 남긴 구멍:** 이 프로토타입은 이제 **태그 기반 점수(컨셉 일치도)로만** 3장을 고른다. 확정된 AI 방식(**이미지 임베딩 + 벡터 유사도** · §15)이 실제로 작동한다는 걸 **화면으로 보여주는 부분이 없다.**

→ **착수 전 스파이크①(어느 임베딩이 '무드'를 잡나 · PRD 부록 A)의 무게가 그만큼 커졌다.** 이전엔 "프로토타입에서 이미 되던데"라고 말할 수 있었지만, 이제 그 근거가 없다.

→ 실서비스 계획은 안 바뀐다: 온보딩에서 **고른 사진들의 임베딩**이 질의가 된다(FR-1·FR-2). 올리는 사진에서 고르는 사진으로 **입력만 바뀐 것**이다.

## 5. MVP 링크 제출 방법

프로토타입은 **단일 HTML + 이미지 폴더**라 빌드가 필요 없다. 그대로 정적 호스팅에 올리면 링크가 된다.

**가장 빠른 방법 (선택):**
- **Netlify Drop** — [app.netlify.com/drop](https://app.netlify.com/drop) 에 `prototype/` 폴더를 **드래그&드롭**. 계정 없이 즉시 URL 생성. *(가장 쉬움)*
- **GitHub Pages** — 레포에 올리고 Settings → Pages 활성화. 무료·영구.
- **Vercel** — 폴더 드래그 배포. 나중에 실제 앱과 같은 스택.

> ⚠️ **제출 시 반드시 함께 적을 것:** "날씨는 **기상청 단기예보 실연동**(웹 주소로 열었을 때). 파일을 더블클릭해 열면 중계 서버가 없어 예시 날씨로 내려가며, 화면에 그렇다고 표시된다" — 심사자가 파일로 열어보고 **자동화가 안 된 것**으로 읽지 않게.

**모바일에서 보기:** 프로토타입은 모바일 화면 비율(`#phone` 프레임)로 설계돼 있다. 데스크톱에서도 폰 프레임 안에 렌더된다.
